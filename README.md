# Evidence-Backed Capability Portfolio

## 中文

把 AI 能力整理成可核验的简历、作品集或数字简历。

核心原则：每项能力都连接真实问题、本人决策、交付物和可核查结果；不虚构经历或数据。

## English

Turn AI capabilities into verifiable resumes, portfolios, or digital resumes.

Core principle: connect every capability to a real problem, the creator’s decisions, deliverables, and checkable results. Do not invent experience or metrics.

- `test-prompts.json` — 6 routing test prompts / 6 条路由测试题
- `test-results.md` — Historical test record / 历史测试记录
